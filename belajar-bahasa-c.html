Identifier: uji nama buatanmu

Identifier adalah nama yang kamu tentukan sendiri, misalnya nama variabel, konstanta, atau fungsi. Ketik sebuah nama dan lihat aturan mana yang terlanggar.

Coba:

    32 kata kunci (keyword)

    Kata kunci punya makna tetap, jadi tidak boleh dipakai sebagai identifier. Cari atau klik salah satunya.

    Klik sebuah kata kunci.

    Tipe data dasar

    Tipe data menentukan jenis nilai, jumlah memori, dan rentang nilai. Klik satu baris untuk melihat kotak memorinya (satu kotak = 1 byte).

    TipeJenisMemoriRentang
    Kenapa memilih int untuk bilangan bulat lebih efisien daripada float atau double? Karena memori yang dipakai lebih hemat dan program lebih cepat.

    Catatan: pada buku, rentang char tertulis -127 s.d. 128 dan long -9,2×10⁸; nilai yang benar -128 s.d. 127 dan ±9,2×10¹⁸. Tanyakan ke gurumu ya.

    Variabel: rakit deklarasimu

    Variabel adalah tempat di memori untuk menampung data. Ia punya tiga hal: nama, nilai, dan tipe.

    Kosongkan kolom nilai untuk deklarasi tanpa nilai awal. Tiga contoh cepat:

    Variabel lokal vs global
    int total = 0; // global: bisa dipakai di mana saja
    int main(){
      int x = 5; // lokal: hanya hidup di main
    }
    Pilih salah satu variabel.

    Konstanta: nilai yang dikunci

    Konstanta tidak berubah selama program berjalan. Di bahasa C, tulis dengan kata kunci const.

    Tekan tombol untuk mencoba.

    Urutan soal dan pilihan jawaban diacak setiap kali main.
